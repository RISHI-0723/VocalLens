# VocalLens Pilot Dataset Card

## Summary
This is a **synthetic, controlled pilot dataset** for exercising and verifying the
VocalLens analysis pipeline. It is **not natural human speech** and must not be
presented as evidence of performance on real speakers.

- **Recordings:** 36 (6 passages x 6 variants). Actual count; regenerated by
  `python scripts/build_dataset_manifest.py`.
- **Passages:** 6 short, original English sentences written for this repository
  (no third-party text).
- **Variants per passage:** `reference`, `pace_fast`, `pace_slow`, `long_pause`,
  `monotone`, `energy_drop` (one reference + five controlled flawed variants).
- **Flaw families:** pace, pause, pitch_variation, energy_dynamics.
- **Splits (by passage, no leakage):** train = p01–p04 (24), val = p05 (6),
  test / held-out = p06 (6).
- **Language:** English (`en-US`).
- **Sample rate:** 16 kHz mono, PCM_16 WAV.

## How it was produced
`vocallens.synthesis` renders each word as a short voiced tone (fundamental +
harmonics) with a raised-cosine envelope and near-silent inter-word gaps.
Controlled transforms produce each variant:

| Variant | Transform | Intended flaw |
|---|---|---|
| `pace_fast` | word+gap durations x0.60 | faster pace |
| `pace_slow` | word+gap durations x1.55 | slower pace |
| `long_pause` | +1.1 s gap after the 2nd word | over-long pause |
| `monotone` | pitch flattened to constant F0 | reduced pitch variation |
| `energy_drop` | amplitude x0.30 on the 2nd half | lower relative energy |

## Ground truth
Each recording has an annotation in `annotations/<recording_id>.json` with:
- `word_timings`: start/end for every word, **known by construction** (not
  forced-alignment output). The pipeline consumes these via the alignment
  `provided` backend, clearly labeled as provided ground truth.
- `flaw_intervals`: the intended flaw family and time span, defined by the
  transform (not inferred after observing model output).

## Intended use & limitations
- **Intended use:** controlled engineering/feasibility tests — verifying that an
  expected feature change occurs under a known perturbation, and exercising the
  full pipeline, dashboard, and exports end to end.
- **Limitations:** tonal fixtures lack formants, coarticulation, real prosody,
  room acoustics, and microphone variation. Results here are feasibility
  evidence only and do **not** generalize to real speech. Forced-alignment
  behavior on real audio is assessed separately (see `reports/alignment_feasibility.md`).
