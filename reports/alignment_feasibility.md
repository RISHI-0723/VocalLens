# Alignment Feasibility Report

**Date:** 2026-10-13
**Environment:** Windows 11, Python 3.11.9 (CPU only).
**Budget:** 30-minute focused feasibility window (ARCHITECTURE.md §5).

## What was attempted
1. Installed WhisperX as the canonical primary aligner.
2. Implemented a forced-alignment adapter (`src/vocallens/alignment.py`) with:
   - a real `whisperx` backend (loads the alignment model, runs `whisperx.align`,
     validates and maps word timings),
   - a `provided` backend for synthetic fixtures whose word boundaries are known
     by construction (clearly labeled, not forced-alignment output),
   - explicit `unavailable` / `timed_out` / `failed` states that never fabricate
     timestamps.

## Actual outcomes
- **WhisperX installs and imports** (`whisperx==3.8.6`, with `torch==2.8.0`,
  `torchaudio`, `pyannote-audio`, `transformers`, `ctranslate2`, …).
- **Dependency conflict (material):** WhisperX's dependency set requires
  `numpy>=2.1` and installs `protobuf==7.x`. `protobuf>=7` is **incompatible with
  Streamlit's `protobuf<7` pin**, which would break the dashboard. To keep the
  reproducible demo stable, the core environment is pinned to `numpy<2` and
  `protobuf<7`; **WhisperX is therefore an optional, separately-installed path**
  (`requirements-align.txt`), not part of the core install.
- **3-clip real-speech gate: BLOCKED (no data).** The canonical gate requires
  three short *licensed/consented real English speech* clips. No such clips are
  available in this environment, and no audio may be downloaded without verified
  licensing/consent. The pilot dataset is **synthetic tonal fixtures with no
  phonetic content**, for which forced alignment of a transcript is not
  meaningful. Running WhisperX against tonal fixtures would not produce an
  interpretable feasibility result, so it was not reported as one.

## Decision (honest, within spec)
- For the synthetic pilot dataset, the pipeline uses the `provided` ground-truth
  alignment backend. These word boundaries are generated by construction
  (`vocallens.synthesis`) and are labeled `backend="provided"` with an explicit
  warning that they are not forced-alignment output.
- The WhisperX adapter is implemented and exercised by the alignment unit tests
  (fallback/unavailable paths). It will perform real forced alignment when (a)
  real speech + a transcript are supplied, (b) WhisperX is installed from
  `requirements-align.txt`, and (c) its alignment model downloads succeed.
- **No word timestamps are ever fabricated** when alignment is unavailable; the
  pipeline returns `unavailable`/`partial` and limits time-grounded comparisons
  to mapped regions.

## Status
**WhisperX real-speech feasibility gate: BLOCKED (no licensed real-speech data;
dependency conflict with the dashboard stack).** Adapter implemented; provided
ground-truth backend used for the synthetic pilot. This is recorded as a blocker,
not a PASS.
